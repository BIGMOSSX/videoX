# 多市场 UGC 语言扩展规格

状态：功能已实施并通过本地模拟测试；四市场真实视频发音、口音和口型仍待样片人工验收。

## 目标与范围

在现有客户端使用已有组件增加“市场 / 口播语言”。默认巴西；同一批次的 1–10 条任务使用所选市场，每个任务持久化自己的选择：

| 市场 | 稳定值 | 口播 |
|---|---|---|
| 巴西 | `pt-BR` | 巴西葡语 |
| 墨西哥 | `es-MX` | 墨西哥西班牙语 |
| 美国 | `en-US` | 美式英语 |
| 菲律宾 | `fil-PH` | Filipino（菲律宾语） |

语言选择覆盖导演脚本、草稿展示、最终视频提示词、任务历史、审查文案和场景检索词。操作界面仍为中文。用户可使用已有图片和场景；市场切换不替换素材，不根据照片推断国籍。Pinterest 仍只读取已授权 Board，不声称支持全站采集。

## 输入与提醒

- 手动台词逐行对应视频，原文保留，不自动翻译或改写。切换市场不清空台词。
- 创建导演草稿前按行检查：有充分证据为另一语言时，显示目标语言与行号，例如“第 2 条台词可能是英语，当前选择墨西哥西班牙语，请检查”。允许保留原文继续；修改台词或市场后重新检查。
- 短句、专有名词、无重音葡语/西语、菲律宾语夹杂英语、数字和 emoji 可能无法可靠识别；不把不确定判成错误，不声称能识别地区口音。空台词不检查。
- 建议复用已配置的导演模型进行结构化语言判断；这是额外调用，界面要说明可能产生少量费用。检查失败或无法判断应明确说明并允许继续，不能静默显示通过。不得因此发起视频付费生成。
- 草稿审核时继续显示相关提醒和任务语言。批量行号要与实际提交的非空台词映射一致。

## 生成与兼容

- 语言从任务请求传至导演规则、结构化草稿、提示词及各视频网关。非巴西任务不能残留强制巴西或 pt-BR 的指令；导演说明仍可中文，只有口播是目标语言。
- 保留 15 秒、9:16、一镜到底、唯一人物、场景、手机正向及游戏画面引用等原有约束。字幕/额外旁白规则照旧。
- 旧任务缺少语言字段时按 `pt-BR`；旧 `dialogue_pt_br` 草稿、checkpoint 和已提交任务必须可读取。旧 `draft_ready` 任务继续提交时沿用原语言；进行中的任务继续按原 task ID 查询，绝不重新提交。新旧字段同时出现且冲突时明确报错，不静默选一个。
- 存储语言为任务快照，历史卡片不能依赖当前表单。服务商语言以提示词表达，不虚构供应商 API 参数。生成包中记录任务语言。
- 场景检索词根据市场本地化；不要把英语输入直接跳过市场转换当作地区判断。Pinterest 授权和素材使用方式保持原有设计。
- 不改变模型或网关。现有 Flova 720p 与通用提示词中的 480p 冲突需在实施时核实并修正为所选服务一致，避免影响现有路径。

## 验收标准

1. 四市场单条与 10 条批量均能创建草稿；每条请求、草稿和最终 prompt 的目标语言一致；非法语言明确拒绝。
2. 手动台词原样保留；明显异语言按准确行号提示，允许继续；修改内容或市场触发重新检查。短句、品牌词及 Taglish 不误报为确定错误；失败提示准确。
3. 四市场的导演输入和三个网关的提交 prompt 无冲突；巴西默认路径行为不退化，人物、场景、手机和时长约束保留。
4. 旧数据、旧 checkpoint、旧待提交草稿、进行中任务及历史展示均兼容；重复提交与待确认状态保护不退化。
5. 前端键盘操作、可读提醒与窄屏可用；后端、前端、打包相关测试通过。
6. 模拟测试仅证明数据与指令传递。四市场实际发音、口音、语言及口型需真实样片人工听看；未生成样片不得声称已通过。付费调用前说明模型、数量及费用，并遵守项目现有付费确认流程。

不在本次范围：新增 Mac 一键启动、调整 API 凭据、重做界面、发布或上传本地真人图片。
